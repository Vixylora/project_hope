# Raven — Tasks

Tasks assigned to Raven by Atom. Raven researches, then writes findings
into `Raven/Reports/`.

## Format
`X.Y_task_name.md`
- `X` — major version: a new research directive
- `Y` — minor version: a follow-up or narrowing of the same research

## Each task file includes
- **Question(s)** — precisely what needs answering (vague research tasks
  produce vague research — be specific)
- **Why it matters** — what decision this research feeds into
- **Deliverable** — a findings report, a comparison, a recommendation
  with sources
